The pipeline uses the following tools:
1. phyluce 1.7.2
2. SPAdes 3.1.15
3. bwa 0.7.17
4. bcftools 1.22
5. DamageProfiler 1.1
6. vcftools 0.1.17
7. samtools 1.22.1
8. fastp 0.22.0

Conda environments referenced in the scripts:
1. phyluce-1.7.2
contains phyluce-1.7.2 and dependencies
2. fastp
contains fastp 0.22.0



Workflow overview:
1. Make config for illumiprocessor with sample names, adapter seqs for raw reads. conf CANNOT be an RTF file, need to download blank .conf file used in previous illumiprocessor script and overwrite. Some sample name formats from GSL are incompatible with illumiprocessor due to underscores and may need to be manually renamed to fit the following convention: <site><year><two digit sample number>
csv headers must be ordered as follows: plate	well	i7	i5	oligoname	libraryname

```
make_illumiprocessor_config.py
```

2. Second round of read cleaning using fastp: more aggressive trimming for old samples (t1 samples and historical), less aggressive for contemporary samples

```
fastp_clean_reads_historical.sh
fastp_clean_reads_contemporary.sh
```

3. SPAdes assembly using PHYLUE wrapper script

```
phyluce_SPAdes_assembly.sh
```

4. Match contigs to probes, get match counts, and generate complete and incomplete data matrices. This scripts combines multiple steps of the PHYLUCE pipeline and requires arguments for the group ID (used for parallel processing of different sample groups), path to the UCE probe set, and path to the contigs generated by SPAdes. 

The sqlite database created at uce-match-${group}/probe.matches.sqlite was used to manually inspect UCE contig results per sample and select a suitable reference sample for alignment and variant calling

```
phyluce_match_contigs_get_counts.sh
```

5. Extract FASTA sequences by locus for the selected reference sample (MP2303)

```
phyluce_get_ref_fastas.sh
```
