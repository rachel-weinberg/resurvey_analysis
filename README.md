This repository contains all of the scripts used to complete the analyses in Weinberg et al (in prep). Detailed notes on the workflows and corresponding scripts used for each step are split into two parts. 

1. Read cleaning, assembly, UCE contig extraction, alignment, and variant calling steps are detailed in uce_preprocessing/preprocessing_workflow.md

2. Population genetic analyses are detailed in popgen_analysis/population_genetics_workflow.md


# Scripts for generating maps and plotting behavioral data are located in /maps_behavior/

# Utility scripts for data conversion and making config files are located in /utils/

### Abbreviations ###
Some site abbreviations in the analysis code differ from those in the main text. Abbreviations in the main text were edited to maintain consistency with the site codes used in Tsutsui et al. 2000 (PNAS). Abbreviations used in the analysis are as follows:


# S1 = Survey 1 (equivalent to t1 in main text)
# S2 = Survey 2 (equivalent to t2 in main text)
# LSC = Large Supercolony
# LH = Lake Hodges Supercolony
# LS = Lake Skinner, equivalent to SK in main text

# Site abbreviations that differ from main text

# SAL = Salinas, equivalent to SA in main text
# SAU = Sausalito, equivalent to SL in main text
# SLO98 = San Luis Obispo, equivalent to SO in main text
# LJM = La Jolla Mesa, equivalent to LM
# LJC = La Jolla Coast, equivanet to LC
