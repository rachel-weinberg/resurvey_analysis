This repository contains all of the scripts used to complete the analyses in Weinberg et al (in prep). 

The UCE analysis scripts are split into two parts for preprocessing and population genetic analysis. Detailed notes on the workflows are located in markdown files within each directory.. 

1. Preprocessing scripts located in uce_preprocessing. Read cleaning, assembly, UCE contig extraction, alignment, and variant calling steps are detailed in preprocessing_workflow.md

2. Population genetic analyses are located in the popgen_analysis folder. The populgation genetic analysis steps are described in popgen_analysis/population_genetics_workflow.md

Utility scripts for data conversion and making config files are located in /utils/


Scripts for generating maps and plotting behavioral data are located in /maps_behavior/



### Abbreviations ###
Some site abbreviations in the analysis code differ from those in the main text. Abbreviations in the main text were edited to maintain consistency with the site codes used in Tsutsui et al. 2000 (PNAS). Abbreviations used in the analysis are as follows:


S1 = Survey 1 (equivalent to t1 in main text)
S2 = Survey 2 (equivalent to t2 in main text)
LSC = Large Supercolony
LH = Lake Hodges Supercolony
LS = Lake Skinner, equivalent to SK in main text

Site abbreviations that differ from main text

SAL = Salinas, equivalent to SA in main text
SAU = Sausalito, equivalent to SL in main text
SLO98 = San Luis Obispo, equivalent to SO in main text
LJM = La Jolla Mesa, equivalent to LM in main text
LJC = La Jolla Coast, equivanet to LC in main text
TWC = Temecula Water Culvert, equivalent to TE in main tex
